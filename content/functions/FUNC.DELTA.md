# DELTA

## What it does

`DELTA(number1, [number2])` returns numeric one when the two numbers are equal and zero otherwise. The second number defaults to zero. It is an equality indicator, not an approximate-comparison function.

## Try it

`=DELTA(6,6)` returns `1`; `=DELTA(6,7)` returns `0`; `=DELTA(0)` returns `1`. Summing such results counts exact matches.

## Quirks

Nonnumeric arguments give `#VALUE!` under the documented rule. The equality is applied to the numbers Excel actually received; two decimal expressions that are mathematically equal can arrive as different floating-point values. A tolerance comparison would be a different function.

## How to implement

Apply the numeric argument rules, default the omitted second value to zero, and compare the two admitted values for equality. Return the numeric value one or zero, rather than the logical TRUE or FALSE. For the first example both inputs have the same representation, so the indicator is one. Keep argument errors and failed coercions separate from a legitimate unequal comparison.

## Alternatives

`--(a=b)` expresses a worksheet equality indicator; [GESTEP](https://handbook.dnacalc.com/functions/GESTEP.html) tests an inclusive threshold; [COUNTIF](FUNC.COUNTIF.md) counts matches over a range.

### FN-DELTA-001: DELTA and GESTEP read their second argument first

*Quirk; measured; recorded 2026-11-04.* Applies to DELTA, ERF, GESTEP.

When both arguments of DELTA or GESTEP are bad, the error comes from the second one:
DELTA(TRUE,#REF!) is #REF! and DELTA(#REF!,TRUE) is #VALUE!. With two errors, DELTA gives the
second. ERF reads left to right: ERF(TRUE,#REF!) is #VALUE! and ERF(#REF!,TRUE) is #REF!. A
logical is rejected in either position of these functions, whether typed or held in a cell:
DELTA(TRUE,0) and DELTA(2,TRUE) are #VALUE!, and DELTA(B1,0) with TRUE in B1 is #VALUE!, while
an empty B1 reads as 0 and gives 1.
