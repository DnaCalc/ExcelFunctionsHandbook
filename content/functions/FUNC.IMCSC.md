# IMCSC

## What it does

`IMCSC(inumber)` returns the complex cosecant, mathematically the reciprocal of IMSIN. It returns complex text even if the imaginary component is zero.

## Try it

`=IMCSC("i")` returns approximately `"-0.850918128239322i"`. The reciprocal reverses a pure imaginary value’s imaginary sign; it is not a component-by-component reciprocal.

## Quirks

Complex arguments may be real numbers or text such as `"2-3i"`. Use lowercase `i` or `j`; operands in one call must agree on the suffix. The current parser rejects malformed complex text with `#NUM!` and logical values with `#VALUE!`. A complex result is text, so ordinary worksheet arithmetic does not automatically treat it as a pair of numeric components. A zero denominator gives `#NUM!` in the current reciprocal helper. Near a pole, small changes in the input can cause large changes in the result.

## How to implement

Parse the two coefficients and suffix before doing arithmetic; use the common complex formatter afterward. Retain suffix consistency, suppress a zero component and omit the coefficient one before the imaginary unit. Formatting and parsing have their own fifteen-significant-digit rules, so testing only the algebra misses observable behaviour.

First compute the unformatted complex IMSIN pair `(c,d)`. If `abs(c)>=abs(d)`, use `r=d/c`, `v=1/(c+d*r)`, and return `(v,-r*v)`. Otherwise use `r=c/d`, `v=1/(d+c*r)`, and return `(r*v,-v)`. Reject `(0,0)` before division. The current reciprocal forms one reciprocal and multiplies a component by it; calling generic IMDIV with numerator one forms a different rounded graph. Keep this distinction when reproducing recorded results.

### FN-IMCSC-001: IMCSC takes one scaled reciprocal of IMSIN(z) rather than IMDIV("1", IMSIN(z)), returning #NUM! at 0 and |re| >= 2^27

*Detail for matching Excel's bits; measured; recorded 2026-11-22.*

In Excel 16.0 builds 20430 and 20527, IMCSC(inumber) computes z_sin = sin(inumber) (rejecting
|re| >= 2^27 with #NUM!), returns #NUM! when z_sin = 0+0i (such as 0), and forms 1 / z_sin via
a single scaled reciprocal 1 / (a + b * ratio) multiplied by ratio (which differs after
rounding from IMDIV's two separate quotients), flushing subnormal components to 0. All 1,209
full-bank IMCSC rows match.
