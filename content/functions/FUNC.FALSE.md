# FALSE

## What it does

`FALSE()` returns the logical value FALSE. It takes no arguments. The literal `FALSE` can be
written directly in a formula or cell with the same purpose; Microsoft retains the function
primarily for compatibility with other spreadsheet programs.

FALSE is a logical value, distinct from numeric zero, the text `"FALSE"`, and an empty cell.
A later operation may convert it to a number, but that conversion belongs to the operation
consuming the value.

## Try it

Calculate `=FALSE()`, then try `=ISLOGICAL(FALSE())` and `=ISNUMBER(FALSE())` to inspect its kind.
Use `=N(FALSE())` to request a numeric conversion explicitly.

## Quirks

A valid call has no input-dependent error. A call such as `FALSE(0)` has the wrong argument
count; handling an invalid formula is separate from calculating a valid constant.

Do not use FALSE as a substitute for a missing value. `ISBLANK(FALSE())` and an actual blank
cell answer different questions. Likewise, `"FALSE"` is text until a particular consumer
chooses to interpret it.

## How to implement

Check that the call has zero arguments and return a tagged logical false value. Do not return
numeric 0: `TYPE`, `ISLOGICAL`, `ISNUMBER` and comparisons can observe the distinction.

A compiler may fold the call to a logical literal if that preserves the formula representation
and any evaluation tracing it promises. TRUE and FALSE can share this path with one boolean
parameter. No floating-point arithmetic or clock is needed.

## Version differences

Microsoft documents the function for Microsoft 365 and Excel 2016 through 2024. No comparison
between particular builds is recorded here; the documentation's applicability list is not a
build-by-build test.

## Alternatives

Write the literal `FALSE` in ordinary formulas. [TRUE](FUNC.TRUE.md) is the opposite constant;
[NOT](FUNC.NOT.md) negates a logical test. [NA](FUNC.NA.md) is an explicit unavailable-value
marker when that is the intended meaning, and is an error rather than a logical value.

### FN-FALSE-001: FALSE takes zero arguments, rejects any argument at entry, and returns the logical value FALSE

*Quirk; measured; recorded 2026-11-22.*

In Excel 16.0 builds 20430 and 20527, FALSE() takes no arguments, refuses any supplied argument
at formula entry, and evaluates to the logical FALSE (distinct from text "FALSE"; compares
above numbers and text and below TRUE, and coerces to 0 when passed as a direct numeric
argument while ignored in held ranges by numeric aggregates). Matches 2/2 full-bank and 1/1
pinned FALSE rows.

| Call | Inputs (binary64) | Excel | Recorded in |
|---|---|---|---|
| `FALSE()` | as typed | `FALSE` | Excel 16.0 build 20430, Windows 64-bit; CPU not recorded |
| `FALSE()` | as typed | `FALSE` | Excel 16.0 build 20527, Windows, Compatibility Version 2, cell_value2_bulk; bitness and CPU not recorded |

Basis (measured): Measured across Excel 16.0 build 20430 (1/1 pinned row in
witnesses/FALSE.json) and Excel 16.0.20527 (admit2-answers-false-{scalar,special}.json; 2/2
full-bank rows).
