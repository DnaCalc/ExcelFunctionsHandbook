# COUNT

## What it does

`COUNT(value1, [value2], ...)` counts numeric entries. It measures how many numbers are present, rather than adding their values. Dates stored as Excel serial numbers count as numbers.

## Try it

`=COUNT(8,"12",TRUE)` returns `3` under the documented direct-argument rules. With A1:A4 containing `8`, the text `12`, `TRUE`, and an empty cell, `=COUNT(A1:A4)` returns `1`.

## Quirks

References and arrays count numbers only; their text, logical values, blanks and errors do not count. Direct numeric text and logical constants can count. Consequently COUNT is not a nonempty-cell count, and a formula returning an empty string is text.

## How to implement

Visit every argument while preserving its direct/reference origin. For a referenced or array element increment only for numeric values. For a direct scalar also admit the documented logical and numeric-text cases. Do not increment for an error or unconvertible text. Use an integer accumulator and return the count as a worksheet number. The direct example admits three values even though only one is a numeric literal.

## Alternatives

[COUNTA](FUNC.COUNTA.md) counts nonempty values; [COUNTBLANK](FUNC.COUNTBLANK.md) counts blanks; [COUNTIF](FUNC.COUNTIF.md) and [COUNTIFS](FUNC.COUNTIFS.md) count matches.

### FN-COUNT-001: COUNT counts direct logicals, omitted slots, and yearless date text, ignores references inside arrays, and reads through nested arrays

*Quirk; measured; recorded 2026-11-22.*

In Excel 16.0 builds 20430 and 20527, COUNT(value1, [value2], ...) counts numbers in held
ranges and counts direct numbers, logicals, omitted arguments, and text that parses as a number
or date (including yearless date text such as "1/2", whereas "1/2/2020" is 0 under en-ZA DMY
settings), ignores text/logicals/blanks/errors in cell ranges, does not count references inside
array results (=COUNT(OFFSET(Data!E1,@{0,1,2},0)) -> 0, or 1 for scalar @), and flattens arrays
held inside arrays (e.g. GROUPBY results). Matches 1,212/1,212 full-bank and 120/120 pinned
COUNT rows.

| Call | Inputs (binary64) | Excel | Recorded in |
|---|---|---|---|
| `=COUNT("1/2")` | as typed | `1.0` (`0x3ff0000000000000`) | Excel 16.0.20527.20088 Current Channel, Windows 64-bit (NT 10.0.26200), x86-64, AMD Ryzen 7 4800H, en-ZA |
| `=COUNT("1/2/2020")` | as typed | `0.0` (`0x0000000000000000`) | Excel 16.0.20527.20088 Current Channel, Windows 64-bit (NT 10.0.26200), x86-64, AMD Ryzen 7 4800H, en-ZA |
| `=COUNT(GROUPBY({"East";"West";"East";"north";"West";"east"},{1;2;3;4;5;6},LAMBDA(x,{1,#N/A}),0,0))` | as typed | `3.0` (`0x4008000000000000`) | Excel 16.0.20527.20088 Current Channel, Windows 64-bit (NT 10.0.26200), x86-64, AMD Ryzen 7 4800H, en-ZA |
