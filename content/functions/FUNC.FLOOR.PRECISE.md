# FLOOR.PRECISE

## What it does

`FLOOR.PRECISE(number,[significance])` rounds to a multiple of the absolute step, toward negative infinity in the mathematical convention. The default step is one. The significance sign is ignored and this spelling has no mode argument. Its current quotient-reading approximation is described below.

## Try it

`=FLOOR.PRECISE(-10.3,-3)` returns `-12`. Changing the significance to positive three gives the same value: the step magnitude controls the grid, while the function chooses the direction.

`=FLOOR.PRECISE(31.2,3)` returns `30`. These ordinary examples separate the direction from the significance sign.

## Quirks

The absolute significance is used, including for negative numbers. A zero number or zero significance returns zero. The current wrapper uses a default of one when significance is omitted at the end of the call; an explicitly empty significance slot is read as zero.

The PRECISE spelling does not establish a correctly rounded mathematical result on every input. The current helper applies a fifteen-digit reading to the quotient before choosing the integer count. On Excel 16.0 build 20527, writing a subnormal binary64 value (`±5e-324` through `±(2^-1022 - 5e-324)`) to a cell via `Range.Value2` flushes the cell to `+0`, so a cell-written subnormal `number` or `significance` returns `0` ([sweep-questions-1-ANSWERS.md](../notes/evidence/2026-11-08/sweep-questions-1-ANSWERS.md), `C:\Work\DnaCalc\codex-runs\sweep-questions-1\Q1-subnormal-inputs.json`). On a true computed subnormal `x` in a formula (`EXP(-745)`, `EXP(-730)`, `EXP(-709)`), `FLOOR.PRECISE(x, 1)` returns `0` and `FLOOR.PRECISE(0 - x, 1)` returns `-1`, while a subnormal quotient `number / s` flushes to `0` ([FN-ABS-002](../notes/FN-ABS-002.json)).

## How to implement

1. Read the number and apply the omitted significance default of one. Set `s=abs(significance)` and return positive zero for s equal to zero.
2. Compute the current [fifteen-significant-digit quotient reading](FUNC.CEILING.md#how-to-implement) using ordinary binary64 division, nearest/even decimal quantization and conversion back to binary64.
3. Take the floor of the signed quotient `number/s`. The current helper expresses the negative branch using a positive magnitude quotient and the opposite integer direction, then restores the sign.
4. Multiply the selected count by s with the ported helper’s ordinary binary64 multiplication, normalize zero and apply worksheet number publication.

For `number=-10.3,s=3`, the magnitude quotient is near `3.43333333333333`. Choosing four steps gives `-12`. Do not infer the significance sign from the input’s sign; this spelling discards it.

This branch outline follows the current scalar helper, with the quotient-reading primitive linked above. The exact modern-spelling edge transfer remains open in [FN-FLOOR-002](../notes/FN-FLOOR-002.json); with cell `Range.Value2` subnormal flushing modelled at the witness boundary (`crates/calc-func/src/witness_exec.rs`, commit `c0b94f88ab4e3df5b518329d08ea03cf481abdbe`) and true subnormal `number` inputs accepted (`crates/calc-func/src/catalogue/math.rs`, commit `e042619e35426ffac3d8cfaaa2dd2961abe3d02c`), DNA Calc matches all 1,335 of 1,335 recorded `FLOOR.PRECISE` bank rows (`C:\Work\DnaCalc\codex-runs\sweep-report-2.md`).

## Alternatives

[MROUND](FUNC.MROUND.md) chooses a nearest multiple; [ROUNDUP](FUNC.ROUNDUP.md) and [ROUNDDOWN](FUNC.ROUNDDOWN.md) address decimal positions. [CEILING.MATH](FUNC.CEILING.MATH.md) provides the other directional family.

### FN-ABS-002: Subnormal cell writes and *, /, ^ underflows flush to +0, while +, - and EXP(-745) keep subnormals

*Quirk; measured; recorded 2026-11-08.* Applies to ABS, CEILING, CEILING.MATH, CEILING.PRECISE, DELTA, EVEN, EXP, FLOOR, FLOOR.MATH, FLOOR.PRECISE, GESTEP, INT, ISEVEN, ISO.CEILING, ISODD, ODD, QUOTIENT, SIGN, SQRT.

Writing any positive or negative subnormal binary64 value or -0 to a cell via Range.Value2
stores +0 (0x0000000000000000), while normal extremes 2^-1022 (0x0010000000000000) and ±DBL_MAX
(0x7fefffffffffffff) read back intact. In the 430 recorded bank rows with subnormal or
maximum-finite cell arguments, all 179 subnormal-input rows read back as +0 and match the +0
control (SQRT(-5e-324) is 0, SIGN(±5e-324) is 0, ODD(±5e-324) is 1, EVEN(±5e-324) is 0,
ISEVEN(±5e-324) is TRUE, ISODD(±5e-324) is FALSE, GESTEP(±5e-324) is 1, DELTA(±5e-324) is 1,
and a subnormal divisor or significance in QUOTIENT, CEILING or FLOOR flushes to 0). Formula
literals below 2.2250738585072014E-308 are refused at entry or parsed to 0. Products (*),
quotients (/) and probed powers (^) that fall in the subnormal range flush to +0, whereas + and
- retain subnormals and EXP(-745) holds 0x0000000000000001 in a formula cell. When fed a true
computed subnormal x from EXP(-745), EXP(-730) or EXP(-709) (and 0-x for negative), ABS(±x) is
x, SQRT(+x) is 2^-537, SQRT(-x) is #NUM!, EVEN(±x) is ±2, ODD(±x) is ±1, ISEVEN(±x) is TRUE,
ISODD(±x) is FALSE, CEILING(+x,1) is 1, FLOOR(-x,1) is -1, QUOTIENT(±x,1) is 0, DELTA(x,0) is
0, DELTA(x,x) is 1, GESTEP(+x,0) is 1 and GESTEP(-x,0) is 0, while SIGN(+x) and INT(-x)
transition inside the subnormal range (0 at 0x00000000001c7ea3 and ±1 at 0x0008bfe58468888d).
