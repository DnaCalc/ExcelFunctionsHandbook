# MODE.MULT

## What it does

`MODE.MULT(number1,[number2],...)` returns all values tied for the highest repetition count, as a vertical array. It finds a repeated value, not a middle value or an average.

## Try it

`=MODE.MULT({2,5,2,5,9})` returns a vertical array containing two and five: each occurs twice, while nine occurs once.

## Quirks

Referenced text, logical values and blanks are ignored; numeric zeros count. No repeated numeric value gives `#N/A`. An error or unconvertible direct text can cause an error. Modern Excel needs space for the result to spill.

## How to implement

Collect admitted numbers, normalise positive and negative zero as one key, and count occurrences. Track each key’s first occurrence. Find the largest count; if it is below two, return `#N/A`. Return all keys attaining that count in a single-column array. The current code orders tied modes by first appearance and uses that order for the single-result choice. That is the implementation’s tie policy, not a whole-domain identification from the public function page. Keep the tie case in compatibility tests.

## Version differences

No same-input comparison between named Excel builds is recorded for this function here. The documented behaviour below is not a measurement of every Excel release.

## Alternatives

[MODE.SNGL](FUNC.MODE.SNGL.md) returns a single mode; [MODE.MULT](https://handbook.dnacalc.com/functions/MODE.MULT.html) returns tied modes; [MEDIAN](FUNC.MEDIAN.md) measures a different kind of centre.

### FN-MODE-001: MODE ignores direct text and logicals instead of converting them or giving an error

*Documentation differs from behaviour; measured; recorded 2026-11-04.* Applies to MODE, MODE.MULT, MODE.SNGL.

MODE, MODE.SNGL and MODE.MULT take only numbers from their arguments, even when text or a
logical is typed directly into the call. A direct "2" or TRUE is not converted, so MODE("2",2)
and MODE(TRUE,1) are #N/A: one number, no repeat. Text that is not a number gives no error
either: MODE("x",2,2) is 2, and MODE("x") is #N/A. Error values do come through: MODE(2,2,A3)
with #DIV/0! in A3 is #DIV/0!, and of two errors the first is returned.

Documentation: Arguments that are error values or text that can't be translated into numbers
cause errors.
(https://support.microsoft.com/en-us/office/mode-function-e45192ce-9122-4980-82ed-4bdc34973120)
