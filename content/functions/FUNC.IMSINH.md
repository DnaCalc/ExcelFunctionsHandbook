# IMSINH

## What it does

`IMSINH(inumber)` returns the complex hyperbolic sine. Real and imaginary coefficients use radians where a circular angle is involved. A real-only input has a real-only result; an imaginary input relates to ordinary sine.

## Try it

`=IMSINH("i")` gives about `"0.841470984807897i"`. For a pure imaginary input the real component vanishes and the imaginary component is ordinary sine. `=IMSINH("0")` returns text zero.

## Quirks

Complex text uses lowercase `i` or `j`; the result is text. The current parser gives `#NUM!` for malformed text and the wrapper gives `#VALUE!` for a logical input.

On the real axis the direct function checks EXP's overflow domain and keeps the imaginary component zero without evaluating an infinity-times-zero product. Its reciprocal companion IMCSCH has a wider runtime computation. Large real-axis inputs need a separate comparison from ordinary non-real pairs.

## How to implement

Parse the two coefficients and suffix before doing arithmetic; use the common complex formatter afterward. Retain suffix consistency, suppress a zero component and omit the coefficient one before the imaginary unit. Formatting and parsing have their own fifteen-significant-digit rules, so testing only the algebra misses observable behaviour.

For `z=a+bi`, the mathematical component formula is `sinh(a)*cos(b) + i*cosh(a)*sin(b)`. The current real-axis direct hyperbolic route enforces the exponential overflow domain and avoids an infinity-times-zero imaginary component. The formula is a derivation aid; the named runtime leaves and stores in the current source define its implementation candidate. Validate text output as well as numeric components, and keep unmeasured rounding stages open.

### FN-IMSINH-001: IMSINH uses re+re^3/6+re^5/120 for |re|<=0.01, (1/EXP(-re)-EXP(-re))/2 below 20, and EXP(|re|+LN(cos(im)/2)) above 709

*Detail for matching Excel's bits; measured; recorded 2026-11-22.*

In Excel 16.0 builds 20430 and 20527, IMSINH(inumber) rejects pure-real inputs where EXP(|re|)
overflows with #NUM!, and evaluates sinh(re) as re + re^3/6 + re^5/120 for |re| <= 0.01,
(1/EXP(-re) - EXP(-re))/2 for 0.01 < |re| < 20, and signed EXP(|re|)/2 for |re| >= 20. Off-axis
(im != 0), it checks |im| < 2^27 and for re > 709 or re < -708 evaluates EXP(|re| +
LN(cos(im)/2)) and EXP(|re| + LN(sin(im)/2)) without abs(), returning #NUM! when cos(im) <= 0
or sin(im) <= 0. All 1,288 full-bank IMSINH rows match.
